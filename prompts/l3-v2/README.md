# L3 V2 lesson prompts

This folder is an independent copy of L3 for the revised lesson flow. The
original `prompts/l3` folder remains unchanged.

V2 starts directly with lead-in. There is no warm-up template:

1. Lead-in pre-video welcomes the child, previews the three new words, gives
   the child one clear direction, and starts the Dino and Mia video.
2. Lead-in post-video continues the story.
3. Word, sentence, and wrap-up stages live in V2 and can evolve here without
   modifying the old version. The V2 wrap-up also uses the A1+ language gate.
