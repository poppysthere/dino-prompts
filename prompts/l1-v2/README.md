# L1 V2 lesson prompts

This folder is an independent copy of L1 for the revised lesson flow. The
original `prompts/l1` folder remains unchanged.

V2 has no warm-up and keeps one sentence-teaching stage:

1. Lead-in pre-video welcomes the child, introduces `{{teacherName}}`, and
   completes one short say-hi exchange.
2. Lead-in post-video tells the child that three food words come next.
3. Word teaching covers `apple`, `juice`, and `bread`. Each word page hands
   off to more practice of that same word. It does not introduce a letter or
   letter-sound activity.
4. A short video introduces the sentence `I like bread.` The sentence page is
   the only sentence-teaching page and ends with `[TEMPLATE_FINISH]`.
5. Wrap-up recaps the three words and starts the song.

Production flow:

`lead-in -> word practice -> sentence video -> I like bread -> wrap-up`

Do not add the retired `I don't like apples` template to this V2 flow.
