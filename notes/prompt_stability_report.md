# Prompt 稳定性报告（课中反馈）

**样本**：Prompt 反馈汇总 · 课中 Prompt，有效 23 条  
**覆盖**：L1–L5（L1 5 / L2 6 / L3 2 / L4 3 / L5 6 / 多课共性 1）  
**来源**：教研 9、监课 6、专家 5、内部体验 2、学科运营 1  
**状态**：几乎全部未闭环（「是否完成调整」= 0）

---

## 一句话结论

近期课中最不稳定的，不是偶发口误，而是三类会跨课复现的硬伤：

1. **话术和当前画面/题目对不上**
2. **学生说对了仍循环同一句，课走不下去**
3. **知识点讲错、漏讲，或整页空翻过去**

这三类加起来超过一半。L1 / L2 / L5 都有，不是某一级的特例。

---

## 问题怎么分

按主因归类（一条反馈只算一次）：

| 类型 | 条数 | 对稳定性 | 一句话 |
|---|---|---|---|
| A. 话术 ≠ 画面 / 题目 | 9 | **最差** | 老师说的内容和孩子看到的不是同一件事 |
| B. 循环不结束 / 重复开场 | 3 | **差** | 答对了还不前进，要手动切页 |
| C. 讲错、漏讲、空翻页 | 4 | **差** | 收尾编造本课没学的词，或整页不讲就翻走 |
| D. 指令不清 / 节奏太赶 | 4 | 中 | 没说清读什么、开放题不给时间、指令和内容连在一起 |
| E. 页面和话术不同步 | 2 | 中（偏产品） | 老师已说到下一页，画面还停在上一页 |
| F. 话术崩坏 | 1 | 差但少见 | 句子不完整、语无伦次 |
| G. 客户端 / 环境 | 1 | 不是 prompt | 卡顿、无话筒、音量忽大忽小、识别错误 |

另外有几条是混杂的：图文问题经常和「页面延迟」一起出现；环境问题那条里也夹了图文不符。

---

## A. 话术和图对不上（9 条，最大头）

这是当前最明确的稳定性问题。教研已标成 **「多课共性问题」**。

| 课 | 现象 |
|---|---|
| 多课共性 | 非抽象词也讲句子，句子和图片不匹配（高频词同样出现） |
| L1 U2 L1 | 画面是蓝色，老师示范 “it is red”；magic colors 页领读颜色也对不上 |
| L1 U1 L3 | 绘本封面没有 pencil，老师却说 “it's a pencil”；白布没揭开就让跟读答案 |
| L2 U1 L4 | 画面是三个 good students，老师问 music 是不是 good |
| L2 U3 L7 | 反复练句型，但图片和问的问题不 match |
| L3 U1 L7 | 约 2 分钟讲解与图文无法对应（监课两条，同一课） |
| L4 U1 L2 | 题目考 valley，老师围着 glacier 提问 |
| L5 U3 L7 | 图里只有一个人，老师说 They |

**稳定性含义**：同一套「看图说话 / 看图讲句」逻辑，在多个 Level、多个单元复现。不是单课脚本写错，是 **讲解逻辑没有绑死「当前画面」**。

教研建议（原话）：抽象词才讲句子，非抽象词不讲句子，和管台 AI 绘图逻辑保持一致。

---

## B. 循环不结束（3 条）

| 课 | 现象 |
|---|---|
| L1 U1 L3 | “what's this / It's a pencil / Hello, pencil” 反复问，学生改答法仍不放；需手动 next page |
| L2 U1 L8 | 学生完整说出 “It is a phone” 后仍被要求再说同一句，被评「无趣」 |
| L5 U1 L2 | 正式进入阅读后，仍用 two girls 开场，和前面重复 |

**稳定性含义**：页没有「答对即停 / 达次即走」的硬出口。模型会把正确回答当成继续练的理由，课卡死。

---

## C. 讲错、漏讲、空翻页（4 条）

| 课 | 现象 |
|---|---|
| L1 U3 L8 | 收尾说 learned apple, banana，画面有 orange，老师没说 |
| L2 U3 L7 | 收尾说 we learned a room and bed；本课是 lamp / table / sofa，没学 bed |
| L5 U1 L4 | 让读 two words，thick oil paintings 实际是 three words |
| L4 U3 L8 | 两页没有任何讲解，直接翻过去 |

**稳定性含义**：收尾和知识点数没有跟本课目标词清单走，模型在「总结」时会编或漏。空翻页是另一端：该讲的 beat 被跳过。

---

## D. 指令不清 / 节奏太赶（4 条，集中在 L5）

专家反馈为主，都在 L4–L5 阅读课：

- 开放题不给思考时间和提示，建议要么给支架，要么不要设开放题（L5 U1 L1）
- 没说清让学生读什么，应改成 “Can you read? — Helpful.”（L5 U1 L1）
- 教学指令和教学内容之间没有间隔（L5 U1 L3）
- 句子太长、出字时间短，人物还遮字幕（L4 U1 L3，偏产品）

**稳定性含义**：高阶课不是「说错」，是 **任务交代不完整**，孩子不知道此刻该干什么。

---

## E / F / G. 其余（各 1–2 条）

- **页面不同步**（L1 U3 L9、L2 U3 L11）：话术已到下一页，画面还在上一页；或话术提前说完，页面晚到后又重问一遍。主因更像客户端翻页 / 网络，prompt 侧只能避免「画面没到就剧透」。
- **话术崩坏**（L2 U3 L10）：话语无伦次、句子不完整。量少，但是直接的生成稳定性事故。
- **环境**（L3 U1 L7）：无话筒、卡顿、ASR 错、音量忽大忽小。不算 prompt 问题，但会放大上面所有错误。

---

## 这是 prompt 问题，还是别的？

| 能靠 prompt / 模板修 | 要内容或产品一起修 |
|---|---|
| 讲句必须匹配当前图；非抽象词不硬讲例句 | 课件图、绘本揭布、字幕遮挡 |
| 完整正确作答 → 停这一句，进下一题 | 翻页延迟、话术和页面抢跑 |
| wrap-up 只念本课目标词，禁止编 | 卡顿、话筒、音量、ASR |
| 每页必须讲完再翻，禁止空翻 | |
| 先给短指令，再给内容；开放题要有提示或删除 | |
| 禁止语无伦次 / 半截句出口 | |

---

## 建议先做的 3 件事

1. **把「当前画面」写成硬约束**  
   老师每句讲解只能描述当前图 / 当前题。抽象词才允许讲句；非抽象词看图说词。这是跨课复现最多的一类，优先堵住。

2. **给练习页加硬出口**  
   学生完整说对 → 立刻停该句。同一问最多两轮，到顶就 `[NEXT_STEP]`。不再出现「要手动切页才能走」。

3. **收尾和知识点数死清单**  
   wrap-up 只读本课目标词表，缺一个算失败，多一个没学过的词也算失败。空翻页同样按失败处理。

L5 阅读课的指令/节奏问题可以第二批做：先说清读什么，开放题给提示或删掉。
