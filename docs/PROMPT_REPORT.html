1. The Fix Pipeline 修复流程 —— 每个 bug 如何变成标准

核心思想：每一个真机课堂里发现的 bug，都会被复现成回归测试用例、修复模板、加上机械检查规则（让同类 bug 永远无法复发）、再用真实模型跑完整套测试后才提交上线。
  1. Real device transcript reveals a bug真机课堂录音/记录中发现 bug
  2. Reproduce it as a regression case (eval/cases_*.yaml, device ID in the note)复现为回归测试用例（备注中记录设备 ID）
  3. Fix the template (prompts/**)修复 prompt 模板
  4. Add a mechanical checker rule so the bug CLASS can never silently return添加机械检查规则，使这一类 bug 永远无法悄悄复发
  5. Run the full live battery against real models (gpt-5.4-mini / gpt-5-mini / doubao-seed-16)用真实模型跑完整套线上测试
  6. Size lint — every template has a hard line + word budget体积检查 —— 每个模板都有行数/字数硬预算
  7. Commit + push — every fix versioned on GitHub with reasoning提交推送 —— 每个修复都带原因说明，版本化管理
Two disciplines keep this honest 两条纪律保证可信度：
  • Anti-bloat 防膨胀： Every template has a line/word budget. A fix must usually pay for itself by trimming elsewhere. 每个模板有行数/字数预算，加东西通常要在别处删掉等量内容；只有结构性变更才能提高预算，且必须写明原因。
  • Flakiness testing 抗随机性测试： Fixed cases are re-run 3–4 times before we trust them — LLMs fail intermittently. 修好的用例连续重跑 3–4 次才算通过 —— LLM 会间歇性失败，一次通过说明不了问题。

2. The Standards 标准 —— 按课程页面分类的检查器

每一条模型回复都会经过检查器。检查器是一组命名规则，任何一条违反即判定用例失败。以下按课程页面分组。建议 PM 重点看每个折叠块的中文摘要，规则明细可展开查看。

4. The Teaching Doctrines 教学信条 —— 规则背后的人性标准

这些是检查器机械化执行的“人的标准”，全部来自真机课堂中让孩子觉得虚拟老师“太像 AI”的记录。这一节最适合直接给 PM 团队讲。
1. Recast, never correct 重述，绝不纠错
这个年龄任何开口都是胜利。把正确版本当成开心的回应说回去，绝不说“你应该这样说”。
2. Feed the words 直接喂词
卡住的孩子想回答但没有词。递给他一个小菜单（"You can say, yes. Or, no."），任何跟读都算他的回答。
3. Answer first 先回答孩子
孩子反问老师时，老师先像一个真人一样回答，再把话轮接回来。
4. The counter law 计数法则
老师数自己的回复数，这就是节拍。孩子说什么都不增加节拍 —— 页面永远准时结束。
5. Say nothing twice 绝不重复
同一页里任何句子、问题、回应都不说第二遍。重复听起来就像坏掉的机器人。
6. Invite budget 邀请预算
最多两次邀请开口。这是孩子的课堂 —— 不做机械操练。
7. Opt-out is sacred 拒绝神圣不可侵犯
“我不想说”立即、温暖地终止追问。
8. Wait is a job 等待即任务
每一次等待孩子的回复，都要给孩子一个明确、微小、答得上来的任务。
9. Questions a 4-year-old can answer 四岁孩子答得上的问题
开放问题自带选项（"A cat? A dog?"）。二选一优于开放式。
10. Matched catches, no fake praise 真实回应，不假夸
回复必须证明听见了孩子：孩子的词打头，夸奖匹配实际发生的事。
11. Small win first 先赢一次
体验课开场只需要说 "hi" —— 孩子在英语课堂的第一个动作是一个不可能失败的动作。
12. TTS-safe, English-only 语音安全、纯英文输出
写出的每个字都会被英文语音引擎朗读出来。
