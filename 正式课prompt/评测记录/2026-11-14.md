# 正式课 Test02 防重复追问复测记录

日期：2026-11-14。模型：Forge / Azure OpenAI Korea / gpt-5.6-luna。

## 结论

本轮 553 次场景执行中，未检出超额等待、同一完整目标被连续要求三次、重复真实问题、等待与结束标签混用等阻断项。该结论仅针对本次合成文本样本，不是所有自然度或真实儿童体验全部通过。另有 8 个场景保留标点或单轮示范冗余观察项，见下表。

## 修改原则

- 单词教学：一个词合计最多两次回答机会，跨图片、词、短语、句子和求助共用，不分阶段重新计数。
- 其他互动环节：通常两次；只有孩子最新回答有具体新进展且确有必要，才允许第三次。更短的原有限制继续保留。
- 连续不会：老师给出有用的完整示范并自然推进，不继续换个说法追问。孩子答对可提前结束，不为凑轮次加题。
- 先回答孩子真实问题；已回答的内容不重复考。示范指令在前，完整模型在后。收尾不再索要回答。
- L1 问句练习明确示范用途与操作；新页不能沿用旧页的完成状态。IP Call 重复页面就绪事件不重启问候或计数。
- 保留原课程顺序、空规则、媒体、原有动作和控制标签。正式课不增加 IPA、音素或音节拆读；WORD_EVALUATION 仍不启用。

## 怎样验证

1. 静态核对 229 个可读取实例的规则、共享 prompt ID、变量、标签及原生步骤。12 个不可读取的视频上下文仍排除，未伪造内容。
2. 265 次回归场景执行，含 14 次额外独立重复运行；覆盖答对、答错、连续沉默、求助、姓名问答、拒绝、已回答目标、跨页、系统消息封装及重复就绪事件。
3. 288 次逐页场景，覆盖 144 个有互动规则的教学页/活动，每个分别测试沉默与求助。不是 18 节真实整课端到端验收。
4. Harness 按公共规则、模板规则、实际 step 和课程变量组装输入，通过 Forge /debug 调用指定模型。保留对话、版本哈希、检查结果和旧失败记录；只有规则及用例完全一致时复用缓存。
5. 自动规则检查之外，由 agent 按低、中、高级别进行语义复核：支架是否有用、是否接住孩子意思、是否编造画面或经历、收尾是否还暗含新任务。这不是独立真人教研验收。

## 仍需观察，不夸大通过范围

少量弯撇号/冒号和单轮内示范重复仍可能发生。语义复核还发现过将孩子的心情附加到画中对象、沉默后使用成果式表扬、把错误词当成话题展开，以及超出低级别的附带词汇。它们不构成本轮持续追问循环，但属于需要继续打磨的真实质量问题。不能据此宣传“零语义错误”或“完全像真人”。

## 发布与边界

仅用于 Test02 测试课程。部署采用 Lesson 级隔离、独立公共规则、旧版本备份、逐项回读及未修改实例审计；实际发布结果以 deployment verification 为准。Git 保存原始规则和映射，体验课目录保持分开。

本轮没有验证 TTS 发音、真实 ASR、儿童实测或 App 播放/翻页接线。Prompt 的轮次限制不是确定性的程序保证；若要从产品层杜绝超额追问，建议应用端同时维护真实页面计数并拦截超额等待，该工程措施不在本次修改范围。

发布核验已完成：Test02 的 18 节课、108 个修改实例、276 处规则全部回读一致。其余 121 个实例及 14 个原共享 prompt 保持不变。
