# 正式课提示词修复候选 · 2026-11-16

本目录保存修复后的 **132 个活动、322 段规则**及逐实例映射。它是尚未发布的源码候选，`accepted=false`；不是 Forge 线上回读快照。外层 `正式课prompt/L1` 至 `L6` 仍是 11 月 14 日已核验版本。

修复重点：去标签历史下的页内计数、答对后继续、一次支架后收尾、非末尾句型解释页只翻页、阅读人物归属，以及 L1 最短问句不原样追问。保留老师的自然角色喜好，身份回答 I'm an AI teacher.，不编造家庭、宠物或生活经历。

- 按 L1–L6 / U1 / Lesson1–3 / 活动 / instance 查看 `mapping.json`。
- `candidate_path` 指向可编辑的原始规则，保留 `{{变量}}` 和原协议标签。
- `baseline_path` 相对外层正式课目录，配套哈希可核对修改前版本。`source_prompt_id` 仅是基线 ID，候选尚无 Forge ID。
- 公共规则需要为目标课程隔离，模板和分步规则需要 Lesson 级绑定；不能凭旧 ID 直接覆盖共享规则。
- 发布前仍须处理评测记录中的未解决项、核实最新 Forge 基线、完成发布验收，再进行 Test02 写入及回读。

运行 `python3 verify_candidate.py` 可离线核对规则、映射及基线哈希，不联网、不发布。结果和边界见 [评测记录](评测记录.md)。
